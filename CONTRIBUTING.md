# Contributing

Report the Windows version, Live version, MPC model/firmware and driver version with an issue.
Describe expected behavior and reproducible steps. Redact usernames, file paths, set names and device
identifiers before sharing logs. Never upload credentials, preference backups, samples or raw USB captures.

Run both tools/check_push_studio.py and tools/check_reliability.py before submitting a change.
Keep hardware tests opt-in and offline previews usable without a device. Changes to rendering geometry
must preserve the associated touch/drag calculations. Document physical tests separately from simulated ones.
